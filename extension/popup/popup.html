First-time setup
  1. Open chrome://extensions → Load unpacked → select extension
  2. Open extension details → Enable Allow access to file URLs (required for local HTML)
  3. Reload this extension so the version is 1.5.1
  4. Stay signed in to Cursor and Gemini in this Chrome profile
  5. Open the local dashboard and click the refresh icon next to Usage

Fetches Cursor and Gemini in the background. No new tab.
